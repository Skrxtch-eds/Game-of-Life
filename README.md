# Game of Life

«Жизнь» — клеточный автомат Джона Конвея. Расставьте клетки на поле и запустите смену поколений.

У каждой клетки восемь соседей. Живая клетка выживает при двух или трёх живых соседях, иначе умирает. Мёртвая оживает, если живых соседей ровно три. Все клетки переходят в следующее поколение одновременно.

## Запуск

Распакуйте архив и запустите `Game of Life.exe`. DLL и папка `assets` должны оставаться рядом с ним.

## Управление

- ЛКМ — поставить или убрать клетку.
- Пробел — следующее поколение.
- Enter — запуск или пауза.
- Escape — очистить поле.

## Сборка из исходников

Нужны CMake, компилятор с поддержкой C++17 и SFML 3, совместимая с компилятором.

Из папки `source`:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Если SFML не найдена, добавьте к первой команде `-DCMAKE_PREFIX_PATH="путь к SFML"`.

Запускайте собранную программу из папки `source`, чтобы она находила `assets`. Для Windows при динамической сборке положите необходимые DLL рядом с полученным `.exe`.
